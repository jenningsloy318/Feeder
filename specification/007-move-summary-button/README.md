# Specification: Move Summarize Button to Article Page Top

## Overview

This specification documents the refactoring of button placement in the article page UI, specifically moving the "Summarize" button from the three-dot menu to the top action bar, and relocating the "Open in Web View" button from the top to the three-dot menu.
