## 5. Parallel Processing Timeline

┌─────────────────────────────────────────────────────────────────────────────┐
│                   Parallel Chunk Processing (3 concurrent)                  │
└─────────────────────────────────────────────────────────────────────────────┘

Time (seconds) →
0s     10s     20s     30s     40s     50s     60s     70s     80s
│       │       │       │       │       │       │       │       │
└───────┴───────┴───────┴───────┴───────┴───────┴───────┴───────┘

Batch 1 (Slots 0,1,2):
Slot 0: [████████████████████] Chunk 0 → Complete (20s)
Slot 1: [████████████████████████] Chunk 1 → Complete (25s, then retry)
        [████] Retry success (5s)
Slot 2: [████████████████] Chunk 2 → Complete (15s)

Batch 2 (Starts when slot available):
Slot 0:         [████████████████] Chunk 3 → Complete (20s)
Slot 1:                 [████████████████████] Chunk 4 → Complete (25s)
Slot 2:     [████████████████] Chunk 5 → Complete (15s)

Batch 3:
Slot 0:                 [████████████████] Chunk 6 → Complete (20s)
Slot 1:                         [████████████████████] Chunk 7 → Complete (25s)
Slot 2:         [████████████████] Chunk 8 → Complete (15s)

...continues with remaining chunks...

Key:
█ = Processing
░ = Waiting (backoff delay)

Progress Emissions:
0s  → Starting(25)
5s  → Translating(1,25)
15s → ChunkComplete(2,25)
20s → ChunkComplete(1,25)
25s → ChunkComplete(3,25)
30s → Translating(4,25)
35s → ChunkComplete(4,25)
...
120s→ Complete(results)

## 7. Configuration Options

┌─────────────────────────────────────────────────────────────────────────────┐
│                        Tunable Parameters                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ Component: TranslationChunker                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ Parameter: maxChunkSize                                                    │
│ Default:  2000 characters                                                  │
│ Range:    1000 - 5000 characters                                          │
│                                                                             │
│ Trade-offs:                                                                │
│   Smaller (1000):                                                          │
│     ✓ More granular progress                                               │
│     ✓ Less likely to hit token limits                                      │
│     ✗ More API calls (slower overall)                                      │
│                                                                             │
│   Larger (4000):                                                           │
│     ✓ Fewer API calls (faster overall)                                     │
│     ✗ Higher risk of timeout                                               │
│     ✗ Coarser progress granularity                                         │
│                                                                             │
│ Recommended: 2000 (balanced for most providers)                            │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ Component: ChunkTranslationCoordinator                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ Parameter: concurrency                                                     │
│ Default:  3 parallel chunks                                                │
│ Range:    1 - 5 parallel chunks                                           │
│                                                                             │
│ Trade-offs:                                                                │
│   Lower (1-2):                                                             │
│     ✓ Safer for rate-limited providers                                     │
│     ✓ Less memory usage                                                    │
│     ✗ Slower overall translation                                           │
│                                                                             │
│   Higher (4-5):                                                            │
│     ✓ Faster overall translation                                           │
│     ✗ Higher risk of rate limit errors                                     │
│     ✗ More memory usage                                                    │
│                                                                             │
│ Recommended: 3 (good balance for most providers)                          │
└─────────────────────────────────────────────────────────────────────────────┘
