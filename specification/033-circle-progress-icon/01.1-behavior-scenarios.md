## Feature: Summarize Progress on Toolbar Icon

### SCENARIO-001: Summarize operation displays circular progress on toolbar icon
**Acceptance Criteria:** AC-01, AC-02 from requirements
**Priority:** P0

**Given** a user is viewing an article with summarize available
**When** the user initiates a summarize operation
**Then** the summarize icon transforms into an indeterminate circular progress indicator with a center stop square
**And** no inline progress bar appears in the article content area

### SCENARIO-002: Cancelling summarize returns to idle state
**Acceptance Criteria:** AC-04 from requirements
**Priority:** P0

**Given** a summarize operation is in progress showing circular progress on the icon
**When** the user cancels the summarize operation
**Then** the summarize operation stops
**And** the icon returns to its default idle state

### SCENARIO-003: Completed summarize restores idle icon and displays result
**Acceptance Criteria:** AC-06, AC-08 from requirements
**Priority:** P0

**Given** a summarize operation is in progress
**When** the summarize operation completes successfully
**Then** the summarize icon returns to its default idle state and is re-activatable
**And** the summary result card is displayed in the article content area

### SCENARIO-004: Summarize error restores idle icon
**Acceptance Criteria:** AC-06 from requirements
**Priority:** P1

**Given** a summarize operation is in progress
**When** the summarize operation fails with an error
**Then** the summarize icon returns to its default idle state and is re-activatable
**And** the error information is displayed in the summary result card

### SCENARIO-005: Re-triggering summarize after completion starts a new operation
**Acceptance Criteria:** AC-06 from requirements
**Priority:** P1

**Given** a previous summarize operation has completed and the icon is in idle state
**When** the user initiates a new summarize operation
**Then** the summarize icon transforms into an indeterminate circular progress indicator again

## Feature: Translate Progress on Toolbar Icon

### SCENARIO-006: Translate operation displays determinate circular progress on toolbar icon
**Acceptance Criteria:** AC-01, AC-03 from requirements
**Priority:** P0

**Given** a user is viewing an article with translate available
**When** the user initiates a translate operation
**Then** the translate icon transforms into a determinate circular progress indicator with a center stop square
**And** no inline progress bar appears in the article content area

### SCENARIO-007: Translate progress reflects paragraph completion fraction
**Acceptance Criteria:** AC-03 from requirements
**Priority:** P0

**Given** a translate operation is in progress with some paragraphs completed
**When** additional paragraphs complete translation
**Then** the circular progress indicator advances proportionally to the completed-to-total paragraph ratio

### SCENARIO-008: Cancelling translation returns to idle state and discards partial results
**Acceptance Criteria:** AC-05 from requirements
**Priority:** P0

**Given** a translate operation is in progress showing circular progress on the icon
**When** the user cancels the translate operation
**Then** the translate operation stops
**And** any partially translated paragraphs are discarded
**And** the icon returns to its default idle state

### SCENARIO-009: Completed translation restores idle icon and shows inline translated text
**Acceptance Criteria:** AC-07, AC-10 from requirements
**Priority:** P0

**Given** a translate operation is in progress
**When** the translate operation completes successfully
**Then** the translate icon returns to its default idle state and is re-activatable
**And** translated paragraph text is displayed inline below the original paragraphs

### SCENARIO-010: Translation error restores idle icon and shows error card
**Acceptance Criteria:** AC-07, AC-09 from requirements
**Priority:** P1

**Given** a translate operation is in progress
**When** the translate operation encounters an error
**Then** the translate icon returns to its default idle state and is re-activatable
**And** a translation error card is displayed in the article content area

## Feature: Concurrent and Sequential Operations

### SCENARIO-011: Summarize and translate run independently with separate progress indicators
**Acceptance Criteria:** AC-02, AC-03 from requirements
**Priority:** P1

**Given** a summarize operation is in progress showing indeterminate circular progress
**When** the user initiates a translate operation on the same article
**Then** the translate icon shows its own determinate circular progress indicator
**And** the summarize icon continues showing its own indeterminate circular progress independently

### SCENARIO-012: Rapid cancel and restart begins a clean new operation
**Acceptance Criteria:** AC-04, AC-05 from requirements
**Priority:** P2

**Given** a summarize operation is in progress
**When** the user cancels the operation and immediately initiates a new summarize
**Then** the previous operation is fully stopped
**And** a new indeterminate circular progress indicator appears on the summarize icon

---

## Feature: Accessibility and Visual Standards

### SCENARIO-013: Summarize progress icon announces operation status for assistive technology
**Acceptance Criteria:** AC-11 from requirements
**Priority:** P1

**Given** a summarize operation is in progress
**When** assistive technology queries the summarize icon
**Then** the icon provides a content description indicating summarization is in progress and cancellation is available

### SCENARIO-014: Translate progress icon announces paragraph count for assistive technology
**Acceptance Criteria:** AC-11 from requirements
**Priority:** P1

**Given** a translate operation is in progress with a known completed and total paragraph count
**When** assistive technology queries the translate icon
**Then** the icon provides a content description indicating the translation progress count and that cancellation is available

### SCENARIO-015: Circular progress indicator fits within standard toolbar icon dimensions
**Acceptance Criteria:** AC-12 from requirements
**Priority:** P1

**Given** a summarize or translate operation is in progress
**When** the circular progress indicator is displayed on the toolbar
**Then** the progress indicator fits within the standard toolbar icon touch target
**And** the visual indicator area matches the standard icon size
